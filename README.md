# ELUDRA 🇵🇱

ELUDRA is a real-time simulation project focused on:
- managing Earth as a complex system
- preparing and executing Mars colonization
- understanding long-term consequences of human decisions

## Core idea
Decisions made on Earth directly impact the success of space exploration.
There is no rewind. Time flows continuously.

## Current stage
- Concept & simulation design
- MVP planning (Earth → Mars progression)
- No token, no speculation, no hype

## Philosophy
ELUDRA is a system-first project.
Technology serves understanding, not promises.
